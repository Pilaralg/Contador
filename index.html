Manual de Usuario - Automatizador de Cuadrantes

1. Introducción

Bienvenido al Manual de Usuario del Automatizador de Cuadrantes. Esta herramienta web está diseñada para simplificar y automatizar la generación de informes de asistencia y el seguimiento de llamadas de agentes de manera eficiente y precisa.

La plataforma permite cruzar datos de una base maestra de empleados con un historial de transacciones (llamadas) para generar cuadrantes dinámicos, aplicar reglas condicionales y analizar el rendimiento de forma interactiva.

Concepto Clave

La herramienta opera bajo el principio de cruce de datos: requiere un fichero base con el listado oficial de agentes y un segundo fichero con los registros diarios de llamadas. Al combinarlos, se genera un cuadrante consolidado.

2. Instrucciones Paso a Paso

1 Sube tus archivos de datos

El primer paso para utilizar la herramienta es proporcionar los datos fuente. La aplicación requiere dos archivos fundamentales:

  • 1. Fichero AGENTES: Es el documento maestro que contiene la lista oficial de todos los empleados o agentes activos. Esto es crucial para que el sistema sepa a quién debe evaluar.
  • 2. Fichero LLAMADAS: Es el historial o reporte de las transacciones (llamadas) realizadas.

Para cargar los archivos, simplemente haz clic en los recuadros correspondientes que indican "Haz clic aquí para seleccionar" y elige los documentos desde tu ordenador.

2 Configuración del Cuadrante

Una vez cargados los archivos, se desplegará el panel de configuración. Aquí es donde ajustas los parámetros para que el sistema procese correctamente la información.

  • Mapeo de Columnas: Dependiendo de la estructura de tus archivos, deberás indicar al sistema qué columna corresponde a qué dato a través de los menús desplegables (selectores). Asegúrate de asignar correctamente las columnas de Nombre de Agente, Fechas, y otros identificadores clave.
  • Regla de Evaluación de Llamadas: Esta sección te permite definir cómo se visualizará el rendimiento o el resultado en el cuadrante final, especialmente en base a criterios predefinidos (por ejemplo, la regla general mostrada en cabecera: ≤ 3 = "NO"). Las opciones de visualización incluyen:
    • Dejar celda vacía (en blanco): Si el agente no cumple la regla, no se mostrará nada.
    • Mostrar número de llamadas: Muestra el valor numérico exacto de las llamadas realizadas.
    • Mostrar texto personalizado: Permite establecer una palabra clave (como "NO" o "FALTA") para identificar rápidamente a los agentes que no alcanzan el mínimo requerido.

3 Resumen de Datos y Visualización

En el tercer panel, la herramienta procesará la información y te mostrará un Panel de Control con las estadísticas clave del mes: Agentes, Llamadas Mes, y Registros Activos.

Debajo de estos indicadores, encontrarás una tabla generada automáticamente (el cuadrante) donde podrás verificar los cruces de información por agente y día/periodo.

3. Herramientas de Análisis

Análisis Interactivo por Agente

Más allá del cuadrante global, la aplicación ofrece una vista detallada individual. En la sección "Análisis Interactivo por Agente", podrás:

  1. Seleccionar a un agente específico de una lista desplegable.
  2. Visualizar sus estadísticas individuales.
  3. Revisar las descripciones detalladas de su actividad, permitiendo un monitoreo exhaustivo sin necesidad de buscar en todo el cuadrante general.

4. Avisos y Resolución de Problemas

Aviso de Seguridad: Inconsistencia de Datos

Si la plataforma detecta nombres que tienen llamadas registradas en el Fichero LLAMADAS pero que no existen en el Fichero maestro de AGENTES, se activará un panel de "Aviso de Seguridad".

El sistema listará a estos agentes huérfanos y los excluirá del cuadrante automáticamente. Si ves este aviso, te recomendamos revisar tu Fichero AGENTES para asegurar que está actualizado o verificar que no haya errores tipográficos en los nombres entre un archivo y otro. Tienes la opción de ignorarlos o incluirlos forzosamente en el cuadrante.
